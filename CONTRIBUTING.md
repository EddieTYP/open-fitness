# Contributing to Open Fitness

Issues, bug reports, reproducible test cases, and design discussion are welcome.
Please do not include private health records, database files, exports, tokens,
credentials, or identifiable screenshots.

Substantive external code contributions are temporarily closed while the
project publishes the contributor terms needed for its AGPL and possible
commercial dual-license model. Please open an issue before preparing a code pull
request. A future contribution policy will state the exact inbound license or
contributor agreement before such pull requests are accepted.

Small reports and suggestions remain welcome in the meantime. See
[docs/LICENSING.md](docs/LICENSING.md) for why the distinction matters.
